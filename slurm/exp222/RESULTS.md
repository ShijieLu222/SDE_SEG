## 消融分析

### 1. Cross-Task Projection Loss 的整体效果

CT Loss 的提升效果**取决于基础配置**：

| 配置 | MSE 两批均值 | Cosine 两批均值 | exp221 基线 | MSE Δ | Cosine Δ |
|------|------------|----------------|------------|-------|---------|
| MTL+DX     | 65.67%     | 66.07%         | 66.22%     | ↓0.55% | ↓0.15% |
| MTL+Sel    | 66.92%     | 66.41%         | 66.58%     | **↑0.34%** | ↓0.17% |
| MTL+DX+Sel | **68.18%** | 67.82%         | 67.74%     | **↑0.44%** | ↑0.08% |

- **含 Sel 的配置**：MSE CT Loss 在两批中均一致提升（+0.30%～+0.59%），跨批重复性高，效果可靠；
- **纯 DX 配置**：MSE 和 Cosine 均微降，DX 提供的跨任务几何约束与 CT Loss 功能重叠，导致额外约束无法带来增量收益；
- **两批结果高度一致**（MSE MTL+DX+Sel 批1=68.03%，批2=68.33%），说明实验结论可重复。

### 2. MSE vs Cosine：MSE 更稳定，效果更好

| 指标 | MSE（两批均值） | Cosine（两批均值） |
|------|--------------|----------------|
| MTL+Sel 提升量   | **+0.34%** | −0.17% |
| MTL+DX+Sel 提升量 | **+0.44%** | +0.08% |
| 平均 std（6组）  | **±0.61%** | ±0.82% |
| 最高分           | **68.18%** | 67.82% |

- MSE CT Loss 在含 Sel 的所有配置（两批共 4 个实验）上全部为正提升，一致性强；
- Cosine CT Loss 方差更大，MTL+Sel 配置两批均下降，可靠性不足；
- **推荐使用 MSE CT Loss**。

### 3. 组件贡献分解

以两批均值为准，基于 exp221 结果逐步分析各组件的加性贡献：

| 配置（MSE exp222） | mIoU | 相对纯 MTL | 各组件增量 |
|--------------------|------|-----------|-----------|
| MTL only（exp221 参考，~64.8%） | ~64.8% | 基准 | — |
| MTL + DX（exp221） | 66.22% | +1.42% | DX 贡献 |
| MTL + Sel（exp221） | 66.58% | +1.78% | Sel 贡献 |
| MTL + DX + Sel（exp221） | 67.74% | +2.94% | DX+Sel 协同 |
| MTL + DX + Sel + CT-MSE（exp222） | **68.18%** | +3.38% | **CT Loss 额外贡献 +0.44%** |

### 4. 创新点有效性总结

**① CT Loss 在完整模型上实现了持续提升**
- MSE MTL+DX+Sel 两批均值 **68.18%**，超越无 CT Loss 的 exp221 最强基线（67.74%）**+0.44%**；
- 两批独立实验（批1=68.03%，批2=68.33%）均超越基线，结论可重复。

**② Single Projection + MSE 设计合理**
- 单向投影（seg → depth space）配合 MSE 损失，以最低实现复杂度取得最佳效果；
- 对比 Cosine 版本，MSE 版在稳定性和绝对性能上均更优。

**③ CT Loss 与 Sel 具有互补协同效应**
- Sel 决定**哪些样本**参与训练，CT Loss 决定**跨任务特征如何对齐**，二者从不同维度优化半监督学习，协同效果显著（+0.34%～+0.44%）；
- CT Loss 与 DX 存在功能冗余，未来可探索在含 DX 配置中降低 λ（如 λ=0.5）以消除干扰。
